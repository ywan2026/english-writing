# Writing Studio ✎

송례중학교 3학년 영어 · 서술형·논술형 쓰기 + 자가채점 웹앱

| 번호 | 문항 | 유형 | 배점 | 성취기준 |
|---|---|---|---|---|
| 1 | 3Rs 실천 방법 | 서술형 | 6 | 9영03-02 · 9영04-05 |
| 2 | 도표 비교 문장 | 서술형 | 4 | 9영03-03 · 9영04-03 |
| 3 | 교복 찬반 인터뷰 | 논술형 | 8 | 9영03-04 · 9영04-02 |
| 4 | 고객센터 문의 이메일 | 논술형 | 8 | 9영04-06 |

- **학생 화면** `index.html` — 학번 5자리 + 이름으로 로그인 → 선생님이 연 문항 풀기(자동 저장) → **제출하기** → 예시 답안·채점 기준표 공개 → 채점 요소별 점수 + 근거 한 줄 + 고쳐 쓰기 → 저장
  - 과제 완성(수행) 점수는 학생이 체크한 **조건 개수**로 자동 계산됩니다. 단어 수 조건(3번 40단어, 4번 50단어)은 앱이 자동으로 확인합니다.
  - 채점 시 유의점(과제 점수가 낮으면 다른 요소는 0~1점만)이 선택지에 바로 반영됩니다.
  - 제출한 답안은 고칠 수 없습니다(서버 코드에서 막음). 고쳐 쓴 답안은 따로 저장됩니다.
- **교사 화면** `teacher.html` — 상단 메뉴의 **🔐 관리자 모드** → 교사 암호 입력 → 문항 공개/닫기 스위치, 전체 현황(10초마다 갱신), 문항별 답안 보기, 제출 취소, 학생 기록 삭제, **CSV 내보내기**
  - 교사 암호는 Apps Script 편집기 안의 `TEACHER_PASSWORD`에만 넣습니다. 이 공개 저장소와 웹페이지 코드에는 암호가 없습니다.

## 피드백 (CSV → Claude → CSV)

API 키 없이, 교사가 Claude에서 피드백을 만들어 올리는 방식입니다. 자가채점까지 마친 답안이 대상입니다.

1. 교사 화면 왼쪽 **피드백 → 피드백 만들기 (CSV)** → 문항·반을 고르고 **CSV 내려받기** (이미 피드백이 있는 답안은 기본으로 빠짐)
2. **📋 프롬프트 복사** → claude.ai 새 대화에 CSV를 첨부하고 프롬프트를 붙여 넣기 → Claude가 만든 `피드백_완료.csv` 내려받기
   - 프롬프트 원문: [`feedback-prompt.md`](feedback-prompt.md) (문항·조건·채점 기준표·예시 답안이 들어 있어 피드백의 결이 일정하게 유지됨)
   - 피드백용 CSV에는 학생 이름을 넣지 않고 학번만 넣습니다.
3. 같은 화면 3단계에 CSV를 끌어다 놓기 → 미리보기(새로 입력 / 덮어씀 / 건너뜀) 확인 → **입력하기**
4. **1~4번 피드백** 화면에서 검토하고, 필요하면 **수정**으로 직접 고친 뒤, 오른쪽 위 **학생에게 피드백 공개** 스위치를 켜기

- 학생 화면: 왼쪽 **피드백 → 선생님 피드백**에서 문항별로 👍 잘한 점, ✏️ 고칠 점, ✅ 고친 문장을 봅니다. 고친 문장은 학생이 고쳐 쓴 답안과 비교해 바뀐 단어를 초록색으로 표시합니다.
- 공개하지 않은 피드백은 서버에서 아예 보내지 않습니다.
- 스프레드시트 `답안` 시트 오른쪽에 `피드백: 잘한 점 / 고칠 점 / 고친 문장 / 피드백 입력 시각` 열이 자동으로 생깁니다. `설정` 시트의 `fb_q1~q4`가 피드백 공개 여부입니다.

## 구글 스프레드시트 연결하기 (처음 한 번)

데이터는 구글 스프레드시트 `Writing Studio 응답 (3학년 영어 쓰기·자가채점)`의 **설정 / 학생 / 답안** 시트에 저장됩니다.

1. 스프레드시트를 열고 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 모두 지우고 이 저장소의 `apps-script/Code.gs`를 통째로 붙여 넣은 뒤, 맨 위 `TEACHER_PASSWORD = 'CHANGE_ME'`를 교사 암호로 바꾸고 저장(💾)
3. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 검토 → 내 계정 선택 → (경고 화면에서) 고급 → 안전하지 않은 페이지로 이동 → 허용
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 `js/config.js`의 `SCRIPT_URL`에 넣고 커밋
6. 교사 화면에서 공개할 문항 스위치를 켜면 학생 화면에 열립니다. (스프레드시트 `설정` 시트의 TRUE/FALSE를 직접 바꿔도 됩니다.)

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. (새 배포를 만들면 URL이 바뀝니다.)

`SCRIPT_URL`이 비어 있으면 **로컬 모드**로 동작해 그 브라우저에만 저장됩니다(미리보기용).

### 알아 둘 점
- 실시간 연결이 아니라 학생 화면은 30초, 교사 화면은 10초마다 새로 불러옵니다. 교사 화면 메뉴의 **↻ 새로고침**으로 바로 불러올 수 있습니다.
- 학생 답안은 입력을 멈추고 4초 뒤, 그리고 입력 칸을 벗어날 때 저장됩니다.
- 스프레드시트의 열 이름(1행)과 시트 이름은 바꾸지 마세요. 행을 정렬하거나 지우는 것은 괜찮지만, 수업 중에는 손대지 않는 것이 안전합니다.

## CSV 열

학번, 반, 번호, 이름, 문항 번호, 문항, 유형, 상태, 답안, 이메일 서명, 단어 수, 제출 시각, 조건 충족, 과제 점수/근거, 내용 및 구성 점수/근거, 언어 사용 점수/근거, 자가채점 합계, 만점, 고쳐 쓴 답안, 자가채점 시각, 마지막 저장 시각

- 학생 1명 × 문항 1개가 한 줄입니다. 문항별 화면에서 내보내면 그 문항만, 반을 고르면 그 반만 나옵니다.
- 파일 → **CSV 내보내기 (전체 문항·전체 반)** 은 필터와 상관없이 모두 내보냅니다.
- UTF-8(BOM) 형식이라 엑셀에서 바로 열면 한글이 깨지지 않습니다.

## 자주 묻는 것

- **학생이 이름을 잘못 등록함**: 교사 화면 → 전체 현황 → 학생 이름 클릭 → 학생 기록 삭제 → 학생이 다시 로그인
- **실수로 제출함 / 다시 쓰게 하고 싶음**: 답안 → 자세히 → 제출 취소 → 학생이 새로고침
- **학번+이름 로그인의 한계**: 다른 학생의 학번과 이름을 알면 그 학생으로 들어올 수 있습니다. 제출 후에는 답안을 바꿀 수 없도록 서버에서 막아 두었습니다.
- **문항·채점 기준 수정**: `js/items.js`
